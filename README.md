## 1. Общее описание решения

Проект предназначен для вычисления площади и периметра геометрических фигур. Реализованы функции для круга, прямоугольника, квадрата и треугольника. Каждая фигура находится в отдельном модуле и содержит функции `area` (площадь) и `perimeter` (периметр).

Проект написан на языке Python. Для запуска тестов дополнительных пакетов не требуется: используется стандартный модуль `unittest`.

Структура проекта:

```text
geometric_lib/
├── circle.py
├── rectangle.py
├── square.py
├── triangle.py
├── test_circle.py
├── test_rectangle.py
├── test_square.py
├── test_triangle.py
└── README.md
```

## 2. Математические формулы

### Площадь

| Фигура        | Формула   |
|---------------|-----------|
| Круг          | S = πR²   |
| Прямоугольник | S = ab    |
| Квадрат       | S = a²    |
| Треугольник   | S = ah / 2 |

### Периметр

| Фигура        | Формула      |
|---------------|--------------|
| Круг          | P = 2πR      |
| Прямоугольник | P = 2a + 2b  |
| Квадрат       | P = 4a       |
| Треугольник   | P = a + b + c |

## 3. Описание функций

### 3.1. Круг (`circle.py`)

#### Функция `area(r)`

Вычисляет площадь круга по формуле S = πr².

Параметр:

* `r` — радиус круга.

Пример вызова:

```python
area(5)
```

Результат: приблизительно `78.54`.

#### Функция `perimeter(r)`

Вычисляет длину окружности по формуле P = 2πr.

Параметр:

* `r` — радиус круга.

Пример вызова:

```python
perimeter(5)
```

Результат: приблизительно `31.42`.

### 3.2. Прямоугольник (`rectangle.py`)

#### Функция `area(a, b)`

Вычисляет площадь прямоугольника.

Параметры:

* `a` — длина;
* `b` — ширина.

Пример вызова:

```python
area(4, 5)
```

Результат: `20`.

#### Функция `perimeter(a, b)`

Вычисляет периметр прямоугольника.

Параметры:

* `a` — длина;
* `b` — ширина.

Пример вызова:

```python
perimeter(4, 5)
```

Результат: `18`.

### 3.3. Квадрат (`square.py`)

#### Функция `area(a)`

Вычисляет площадь квадрата.

Параметр:

* `a` — сторона квадрата.

Пример вызова:

```python
area(4)
```

Результат: `16`.

#### Функция `perimeter(a)`

Вычисляет периметр квадрата.

Параметр:

* `a` — сторона квадрата.

Пример вызова:

```python
perimeter(4)
```

Результат: `16`.

### 3.4. Треугольник (`triangle.py`)

#### Функция `area(a, h)`

Вычисляет площадь треугольника по формуле S = ah / 2.

Параметры:

* `a` — основание треугольника;
* `h` — высота треугольника.

Пример вызова:

```python
area(6, 4)
```

Результат: `12`.

#### Функция `perimeter(a, b, c)`

Вычисляет периметр треугольника.

Параметры:

* `a` — первая сторона;
* `b` — вторая сторона;
* `c` — третья сторона.

Пример вызова:

```python
perimeter(3, 4, 5)
```

Результат: `12`.

## 4. Тестирование

Для проверки корректности функций написаны модульные тесты на встроенном модуле `unittest`. Каждому модулю соответствует свой файл с тестами:

| Файл с тестами      | Тестируемый модуль | Количество тестов |
|---------------------|--------------------|-------------------|
| `test_circle.py`    | `circle.py`        | 12                |
| `test_rectangle.py` | `rectangle.py`     | 13                |
| `test_square.py`    | `square.py`        | 10                |
| `test_triangle.py`  | `triangle.py`      | 11                |
| **Итого**           |                    | **46**            |

Запуск всех тестов (из корневой папки проекта):

```bash
python -m unittest discover -v
```

Запуск тестов одного модуля:

```bash
python -m unittest test_rectangle -v
```
